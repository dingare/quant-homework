## Q1 — Minimum Units for Overlapping Tasks

### Question

Implement runnable Python 3 `allocate_units(intervals: list[tuple[int, int]]) -> tuple[int, list[int]]`. Task i occupies one identical processing unit throughout the half-open interval from its start to its end. Tasks sharing an endpoint may reuse a unit. Return the minimum unit count and a unit ID for each task in original input order; IDs range from zero to count minus one. Up to 200,000 tasks in arbitrary order; integer endpoints with start strictly before end; identical intervals allowed. Do not modify the input. Empty input returns `(0, [])`.

Target $`O(n\log n)`$ time. Explain the invariant and optimality, distinguish auxiliary from output space, and include runnable tests for shared endpoints, identical intervals and empty input.

### Key solution

Sort tasks by start time while retaining original indices. Keep exactly one heap entry `(latest_end, unit_id)` per allocated unit. If the minimum end is at or before the next start, replace that entry; otherwise allocate another unit. A minimal repair of the user's approach is:

```python
import heapq


def allocate_units(intervals):
    if not intervals:
        return 0, []
    unit = []
    unit_number = 0
    order = [0] * len(intervals)
    sorted_intervals = sorted(enumerate(intervals), key=lambda x: x[1][0])
    for i_index, (s, e) in sorted_intervals:
        earliest = unit[0] if unit else (-float('inf'), 0)
        if earliest[0] <= s:
            if unit:
                heapq.heappop(unit)
            order[i_index] = earliest[1]
            heapq.heappush(unit, (e, earliest[1]))
        else:
            unit_number += 1
            order[i_index] = unit_number
            heapq.heappush(unit, (e, unit_number))
    return unit_number + 1, order
```

When a new unit is required, every existing unit's latest task is still active at the current start. Those tasks and the new task overlap, so every feasible allocation needs at least this many units. Reuse preserves feasibility. This proves minimum count. Time is $`O(n\log n)`$; the heap uses $`O(R)`$ for R units, the sorted task copy uses $`O(n)`$ auxiliary space, and output uses $`O(n)`$ space.

## Q2 — Cycles of a Uniform Random Permutation

### Question

Choose a permutation $`\pi`$ uniformly from all permutations of $`\{1,\ldots,n\}`$, with $`n\ge2`$. Starting at 1, repeatedly apply the same permutation until returning to 1. Let L be the number of distinct labels visited, including 1. Derive the distribution of L. Find the probability that any cycle has length strictly greater than $`n/2`$, and its limit as n tends to infinity. Justify counting; a finite sum is acceptable.

### Key solution

The user's independent chain argument gives:

```math
P(L=\ell)=\left(\prod_{j=1}^{\ell-1}\frac{n-j}{n-j+1}\right)\frac1{n-\ell+1}=\frac1n,
\qquad \ell=1,\ldots,n.
```

Factors are conditional probabilities, not an independence assertion. A long cycle uses more than half the labels, so at most one can exist. For fixed length $`\ell\gt n/2`$, choose its labels, arrange them in one cycle and permute the remainder:

```math
\binom n\ell(\ell-1)!(n-\ell)!=\frac{n!}{\ell}.
```

Each qualifying permutation is counted once. Distinct long-cycle lengths are mutually exclusive, hence:

```math
P(\text{some cycle longer than }n/2)
=\sum_{\ell=\lfloor n/2\rfloor+1}^{n}\frac1\ell
\longrightarrow\int_{1/2}^1\frac{dx}{x}=\ln2.
```

The probability all cycles are at most half the size is one minus this sum. If C counts long cycles, then C is zero or one and $`E[C]=P(C=1)`$.

## Q3 — Uniform Endpoint Estimation and Exact Upper Bounds

### Question

Observe iid samples from $`\mathrm{Uniform}(0,\theta)`$, with unknown $`\theta\gt0`$ and $`n\ge2`$. Compare $`A=2\bar X`$ and $`B=c_nM`$, where $`M=\max_iX_i`$. Choose $`c_n`$ for unbiasedness, derive both MSEs and determine whether one is smaller for every positive parameter. Construct an exact one-sided 95% upper confidence bound U with $`P_\theta(\theta\le U)=0.95`$ for every positive parameter. Derive distributional results used.

### Key solution

The user's independent maximum CDF and mean integration give:

```math
F_M(m)=\left(\frac m\theta\right)^n\quad(0\le m\le\theta),\qquad
E[M]=\frac{n\theta}{n+1},\qquad c_n=\frac{n+1}{n}.
```

The CDF is zero below zero and one above the endpoint. Both estimators are unbiased, so MSE equals variance:

```math
\mathrm{MSE}(A)=\frac4{n^2}\sum_{i=1}^n\frac{\theta^2}{12}=\frac{\theta^2}{3n},
\qquad
\mathrm{Var}(M)=\frac{n\theta^2}{(n+1)^2(n+2)},
\qquad
\mathrm{MSE}(B)=\left(\frac{n+1}{n}\right)^2\mathrm{Var}(M)=\frac{\theta^2}{n(n+2)}.
```

Thus B has strictly smaller MSE for all stated n and positive parameters. For an upper bound, set $`U=aM`$ and calibrate coverage:

```math
P_\theta(\theta\le aM)=P_\theta(M\ge\theta/a)=1-a^{-n}=0.95,
\qquad
\boxed{U=\frac{M}{0.05^{1/n}}}.
```

The rule uses only sample data and n. Repeated-sampling coverage is exactly 95% for each fixed parameter, not merely an asymptotic approximation or a posterior probability statement.

The sample mean can also give an exact one-sided bound. Let $`Z=\bar X/\theta`$ and let its fifth percentile be $`q_{0.05}`$. Its distribution depends only on n, since it is the average of iid standard uniforms:

```math
U_{\mathrm{mean}}=\frac{\bar X}{q_{0.05}},\qquad
P_\theta(\theta\le U_{\mathrm{mean}})=P(Z\ge q_{0.05})=0.95.
```

The mean is not intrinsically two-sided; its exact quantile is less simple. Maximum-based inference is convenient and uses a sufficient statistic: for nonnegative observations, the likelihood is $`\theta^{-n}\mathbf1\{\theta\ge M\}`$. B is a one-to-one scaling of M, so it contains the same information. Smaller estimator MSE alone does not establish confidence-bound coverage.

### Review focus

In part 2, the user gave the correct variance of M but omitted B's squared scaling factor, and omitted the n terms in the variance sum for A. Corrections were supplied; record these as variance sum / scaling omissions, with K/R unresolved rather than inventing prior unfamiliarity.

User acknowledged understanding; independent reconstruction remains unverified. No implementation gap assigned.

## Q4 — Signal Smoothing, Correlation and Trading Costs

### Question

The daily signal $`x_t`$ is iid standard normal and next-day return satisfies $`r_{t+1}=\beta x_t+\varepsilon_{t+1}`$, with $`\beta\gt0`$. Errors are iid, mean zero, variance $`\sigma^2\gt0`$, independent of the entire signal sequence. At time t, strategies take positions:

```math
q_t^A=x_t,\qquad q_t^B=\frac{x_t+x_{t-1}}{\sqrt2},\qquad
J(q)=E[q_tr_{t+1}]-\kappa E[(q_t-q_{t-1})^2],\quad\kappa\ge0.
```

Compare position variances and population correlations with next-day return. Calculate both objectives and determine exactly when each strategy is preferred. Can ranking by forecast correlation disagree with ranking by J? Explain the economic reason.

### Key solution

Both position variances are one. Return variance and forecast correlations are:

```math
\mathrm{Var}(r_{t+1})=\beta^2+\sigma^2,\quad
\mathrm{Cov}(q_t^A,r_{t+1})=\beta,\quad
\mathrm{Cov}(q_t^B,r_{t+1})=\frac\beta{\sqrt2},
\quad
\rho_A=\frac\beta{\sqrt{\beta^2+\sigma^2}},\quad
\rho_B=\frac{\rho_A}{\sqrt2}.
```

Adjacent B positions share a signal, despite the raw signals being iid:

```math
q_t^A-q_{t-1}^A=x_t-x_{t-1},\qquad
q_t^B-q_{t-1}^B=\frac{x_t-x_{t-2}}{\sqrt2}.
```

Thus the expected squared position changes are two and one respectively, giving:

```math
J(A)=\beta-2\kappa,\qquad J(B)=\frac\beta{\sqrt2}-\kappa,
\qquad
J(A)-J(B)=\beta\left(1-\frac1{\sqrt2}\right)-\kappa.
```

A is preferred below that cost threshold, B above it, and both tie at equality. Correlation always favors A.

**Economic interpretation discussed after the drill:** A responds entirely to today's predictive signal; B smooths it with yesterday's signal, which has no incremental predictive value for tomorrow in this model. B sacrifices expected gross return but reduces squared turnover. The square-root normalization equalizes position variance; it does not establish equal P&L variance. Smoothing is worthwhile when saved cost exceeds lost gross return. The quadratic cost penalizes large adjustments disproportionately. J is expected return net of this modeled cost, not Sharpe or a complete portfolio-risk objective. Research should evaluate the positions and costs induced by a forecast, as well as predictive correlation.
