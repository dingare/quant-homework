## Q1 — Cheapest Trip with an Optional Free Edge

### Question

Implement runnable Python 3 `cheapest_trip(n, edges, s, t)` on a directed graph with nonnegative integer costs, using at most one free edge traversal. Return -1 if unreachable. Up to 100,000 nodes and 200,000 edges; parallel edges, self-loops and zero costs allowed. Explain correctness/complexity and test unreachable routes. For edges `[(0,1,5),(1,2,5),(0,2,20)]`, the cheapest trip from 0 to 2 costs 0.

### Key solution

Run Dijkstra on `(node, free_edge_used)`. A paid transition preserves the flag; a free transition changes unused to used. Keep distances and stale-heap checks for the exact state, not just the node. Nonnegative costs justify settling the cheapest state first.

For at most $`k`$ free traversals, use $`L=k+1`$ state layers. A lazy heap gives:

```math
T=O\!\left(LV+LE\log(LE+1)\right),\qquad S=O(LV+LE).
```

### Review focus

**Knowledge gap (K):** Dijkstra was new. **Implementation gap (I):** adjacency, state dimensions, relaxation from the current cost and stale-entry handling. Independently implement and test the two-layer version; final corrected user code remains unverified.

## Q2 — Four Dice Conditioned on a Sum

### Question

Four independent fair six-sided dice have total 10. Without simulation, find $`P(D_1=1\mid\sum D_i=10)`$ and $`P(\max_iD_i\le4\mid\sum D_i=10)`$. Explain the ordered conditional sample space.

### Key solution

Count ordered bounded compositions; all admissible outcomes are equally likely:

```math
N=\binom93-4=80,\qquad
N_{D_1=1}=\binom82-3=25.
```

```math
P(D_1=1\mid\textstyle\sum D_i=10)=\frac{25}{80}=\frac5{16},\qquad
P(\max_iD_i\le4\mid\textstyle\sum D_i=10)=\frac{44}{80}=\frac{11}{20}.
```

### Review focus

**Weak point:** enumerate categories without omissions and apply permutation multiplicities and upper bounds consistently. The second count was correct once the sample space was established. The clarified numerator typo is not a separate conceptual gap.

## Q3 — Omitted-Variable Bias

### Question

With iid observations and finite second moments, suppose:

```math
Y=\alpha+\beta X+\gamma Z+\varepsilon,\qquad
E[\varepsilon\mid X,Z]=0,\qquad\mathrm{Var}(X)\gt0.
```

Regress on an intercept and $`X`$ only. Derive the slope limit and evaluate $`\beta=1,\gamma=-3,\mathrm{Cov}(X,Z)=0.8,\mathrm{Var}(X)=1`$. Can more data or robust standard errors recover $`\beta`$? Explain a negative fitted slope with positive structural effect.

### Key solution

```math
\widehat\beta_{\mathrm{short}}\xrightarrow{p}
\beta+\gamma\frac{\mathrm{Cov}(X,Z)}{\mathrm{Var}(X)}
=1-2.4=-1.4.
```

More observations and robust SE do not correct inconsistency from an omitted correlated effect.

### Review focus

**No conceptual gap established.** Derivation and inconsistency reasoning were independent; the arithmetic typo and English clarification do not change Cold Solve status. Timing was not recorded.

## Q4 — Maximum-Profit Compatible Jobs

### Question

Implement `max_profit(jobs)` for up to 200,000 `(start,end,profit)` jobs with $`\mathrm{start}\lt\mathrm{end}`$. Input order arbitrary, duplicate intervals and negative profits allowed. Endpoints may touch; selecting none is allowed. Explain complexity and test. `[(1,3,5),(2,5,6),(3,6,5),(6,7,4)]` returns 14.

### Key solution

Sort by finish time. Let $`D_i`$ be best profit from the first $`i`$ jobs and $`j_i`$ the number of earlier jobs ending no later than job $`i`$ starts:

```math
D_0=0,\qquad D_i=\max\{D_{i-1},D_{j_i}+p_i\}.
```

In a zero-based loop, use `j = bisect_right(ends, start, 0, i)` and `dp[i+1] = max(dp[i], dp[j] + profit)`. Time $`O(n\log n)`$; space $`O(n)`$.

### Review focus

**Implementation gap (I):** align binary-search bounds with prefix-state indices; preserve the skip option for negative profits. Sorting and DP were independently proposed. Reproduce runnable code with touching endpoints, duplicates and all-negative profits; final independent execution remains unverified.

## Q5 — MA(1) Equivalence, Invertibility, and Fitting

### Question

Let $`X_t=\varepsilon_t+\theta\varepsilon_{t-1}`$, with iid $`N(0,\sigma^2)`$ innovations. Derive mean and autocovariance at every lag. For $`\theta=2,\sigma^2=1`$, find an equivalent representation with $`|\theta|\lt1`$. Can Gaussian observations distinguish them? Explain invertibility and its practical role.

### Key solution

```math
E[X_t]=0,\qquad
\gamma(h)=\begin{cases}
(1+\theta^2)\sigma^2,&h=0,\\
\theta\sigma^2,&|h|=1,\\
0,&|h|\gt1.
\end{cases}
```

The equivalent parameters are $`\theta'=1/2,\sigma'^2=4`$. Both have $`\gamma(0)=5,\gamma(1)=2`$; Gaussianity makes their full observation distributions identical. Invertibility selects a representation allowing stable reconstruction of innovations from past observations. Stationarity holds for every finite $`\theta`$.

### Review focus

**Weak point:** shared-innovation coefficients in lag-one covariance; equivalent representation versus rescaling observations; stationarity versus invertibility. Review moments, likelihood initialization and residual diagnostics in the [fitting backlog](../Backlog.md#time-series-fitting--review-to-do). Independent fitting remains open.

## Q6 — Branching Process Extinction

### Question

Start with $`Z_0=1`$. Each individual independently has offspring count $`K`$ with probabilities $`(0.4,0.2,0.4)`$ for $`K=0,1,2`$, then disappears. Find extinction by generation 2, eventual extinction and root selection, $`E[Z_n]`$, and expected total progeny. Repeat eventual extinction for probabilities $`(0.25,0.25,0.50)`$.

### Key solution

```math
P(T\le2)=0.4+0.2(0.4)+0.4(0.4)^2=0.544.
```

Extinction is the smallest fixed point in $`[0,1]`$ of the offspring generating function, obtained by iterating from zero:

```math
q=0.4+0.2q+0.4q^2\quad\Longrightarrow\quad q=1.
```

```math
E[K]=1,\qquad E[Z_n]=1,\qquad
E\!\left[\sum_{n=0}^{\infty}Z_n\right]=\sum_{n=0}^{\infty}1=\infty.
```

For the alternative probabilities the roots are $`1/2`$ and 1, so extinction probability is $`1/2`$.

### Review focus

**Weak point:** build the fixed point from independent descendant families, justify the smallest root, and distinguish almost-sure extinction from finite expected total progeny. Extinction by generation 2 was independent.

## Q7 — Confidence vs Prediction Intervals

### Question

Under fixed-design normal regression,

```math
Y_i=\alpha+\beta x_i+\varepsilon_i,\quad
\varepsilon_i\overset{\mathrm{iid}}{\sim}N(0,\sigma^2),\quad
S_{xx}=\sum_i(x_i-\bar x)^2\gt0,\quad s^2=\frac{\mathrm{RSS}}{n-2},\quad n\gt2.
```

At $`x_0`$, derive 95% intervals for the conditional mean and one independent new observation. Explain their widths, behavior away from $`\bar x`$, and omitted extrapolation risks.

### Key solution

Set $`d=x_0-\bar x`$ and $`h_0=1/n+d^2/S_{xx}`$. The error representation shows why the covariance vanishes:

```math
\hat\beta-\beta=\frac{\sum_i(x_i-\bar x)\varepsilon_i}{S_{xx}},\qquad
\hat\mu(x_0)=\bar Y+d\hat\beta,\qquad
\mathrm{Cov}(\bar Y,\hat\beta)=\frac{\sigma^2}{nS_{xx}}\sum_i(x_i-\bar x)=0.
```

```math
\mathrm{Var}(\hat\mu(x_0))=\sigma^2h_0,\qquad
\frac{\hat\mu(x_0)-\mu(x_0)}{s\sqrt{h_0}}\sim t_{n-2}.
```

Normality gives independent residual scale estimation. New-observation noise adds an independent variance term:

```math
\begin{aligned}
\text{Mean CI:}&\quad\hat\mu(x_0)\pm t_{n-2,0.975}s\sqrt{h_0},\\
\text{Prediction interval:}&\quad\hat\mu(x_0)\pm t_{n-2,0.975}s\sqrt{1+h_0}.
\end{aligned}
```

The conditional response variance remains $`\sigma^2`$; estimator uncertainty increases away from the design center. Neither interval protects against a wrong model or a changed regime.

### Review focus

**Weak point:** fixed versus random design, coefficient covariance, the t pivot, and response variance versus estimator/prediction-error variance. Independently derive both intervals; guided completion alone is not mastery.

## Q8 — Conditioning and Least Squares

### Question

A real full-column-rank matrix $`A`$ has singular values 10, 1, 0.01. Find the 2-norm condition numbers of $`A`$ and $`A^\top A`$. Compare normal equations with QR and assess whether a large condition number implies faulty implementation. Full column rank makes explicit the original question's intended setting.

### Key solution

```math
\kappa_2(A)=\frac{\sigma_{\max}}{\sigma_{\min}}=1000,\qquad
\kappa_2(A^\top A)=\kappa_2(A)^2=10^6.
```

Normal equations square conditioning; QR/SVD avoid explicitly forming the Gram matrix. Ill-conditioning measures problem sensitivity, even for a stable correct algorithm. For a wide matrix with input nullspace, the Gram matrix would be singular instead.

### Review focus
