## R1 — Fixed points

**Intentional spaced repetition:** [October 10–11 Q2](2026-10-10.md#q2--random-permutation-fixed-points); dependent indicators and variance derivation.

### Question

For a uniform permutation of $`n\ge2`$ objects, let $`F`$ count fixed points. Derive its mean and variance, and discuss independence of the fixed-point indicators.

### Key solution

```math
I_i=\mathbf1\{\pi(i)=i\},\quad F=\sum_iI_i,\quad
P(I_i=1)=\frac1n,\quad P(I_i=I_j=1)=\frac1{n(n-1)}\quad(i\ne j).
```

```math
\begin{aligned}
E[F]&=1,\\
\mathrm{Cov}(I_i,I_j)&=\frac1{n(n-1)}-\frac1{n^2}=\frac1{n^2(n-1)},\\
\mathrm{Var}(F)&=n\frac1n\left(1-\frac1n\right)+n(n-1)\frac1{n^2(n-1)}=1.
\end{aligned}
```

**Priority gap:** translate a count into an indicator sum, then use joint probabilities for covariance. Definition clarified and derivation supplied; independent reproduction remains Pending. ## Q2 — Weighted common-mean inference

### Question

Independent measurements satisfy $`E[X_i]=\mu`$, $`\mathrm{Var}(X_i)=\sigma^2v_i`$, with known $`v_i\gt0`$, unknown $`\sigma^2\gt0`$ and $`n\ge2`$. Among deterministic unbiased linear estimators, derive and prove minimum-variance weights. Under normality, construct an exact 95% CI with an estimated scale and justify degrees of freedom. Evaluate the estimate and SE for $`v=(1,4,9)`$, $`X=(2,4,8)`$.

### Key solution

With $`A=\sum_i1/v_i`$, the inverse-variance estimator has:

```math
w_i=\frac{1/v_i}{A},\qquad
\hat\mu=\sum_iw_iX_i,\qquad
\mathrm{Var}(\hat\mu)=\frac{\sigma^2}{A}.
```

Estimate the common noise scale, then use it in the estimator variance:

```math
s^2=\frac1{n-1}\sum_i\frac{(X_i-\hat\mu)^2}{v_i},\qquad
\mathrm{SE}(\hat\mu)=\sqrt{\frac{s^2}{A}}.
```

Under independent normal observations, the weighted mean and residual scale are independent:

```math
\frac{(n-1)s^2}{\sigma^2}\sim\chi^2_{n-1},\qquad
\frac{\hat\mu-\mu}{\sqrt{s^2/A}}\sim t_{n-1},\qquad
\mathrm{CI}_{0.95}:\ \hat\mu\pm t_{n-1,0.975}\sqrt{\frac{s^2}{A}}.
```

For the numerical example:

```math
A=\frac{49}{36},\quad w=\frac1{49}(36,9,4),\quad
\hat\mu=\frac{20}{7},\quad
\sum_i\frac{(X_i-\hat\mu)^2}{v_i}=4,\quad
s^2=2,\quad\mathrm{SE}(\hat\mu)=\frac{6\sqrt2}{7}.
```

**Weak point:** distinguish common noise scale from mean-estimator variance and SE; derive the weighted residual estimate and exact t pivot. Weights and minimum variance were independently correct, with notation clarified. The interval and numerical values were supplied. ## Q3 — Forecast validation

Coverage: accidental pattern repetition of October 7 Q6 / October 9 Q5; not new coverage.

### Question

Using 1,000 consecutive daily observations, compare two configurations for predicting tomorrow's return from today's information. Specify training/validation windows, refitting and selection. Assess standardizing with all 1,000 days and reporting the selected winner on the same validation periods. What would you investigate if the latest 100 days lose money?

### Key solution

Use chronological rolling or expanding training windows, a specified refit schedule, validation for selection, and a later untouched test for final evaluation. Fit preprocessing parameters only on the training data available at each prediction date.

Whether scaling helps is model-dependent: flags need not be standardized, and tree models often do not benefit. Lagged features can be scaled with fixed training-fitted parameters without losing lag alignment; rolling/window transformations may change level information.

Investigate data/pipeline changes, feature and predictive-relationship shifts, overfitting, regime changes and sampling variation. Recent losses alone do not prove model failure.
