## Q1 — DAG Scheduling with Durations

### Question

Given task durations and dependencies `(u, v)`, with unlimited workers and independent tasks allowed to run simultaneously, find the minimum completion time or return -1 for a cycle. Example: `durations = [3,2,5,4]`, `dependencies = [(0,2),(1,2),(2,3)]`.

### Answer and Feedback

- Result: **P/Y**. This was an **intentional spaced-repetition revisit** of the prior day's topological-sort miss.
- Major improvement: independently retrieved adjacency lists, indegrees, a zero-indegree queue, and BFS / Kahn topological processing.
- Missing step: dynamic programming over the DAG. For each edge `u -> v`, propagate `finish[v] = max(finish[v], finish[u] + duration[v])`.
- Implementation issues: queued children before their indegree reached zero, initialized finish times only for initial roots, used child duration instead of parent finish time, and attempted cycle detection from final queue length rather than processed-node count.

### Retrieval Cue

Initialize `finish = durations[:]`. Kahn BFS guarantees all parents have been processed when a node's indegree reaches zero. Count processed nodes to detect a cycle. The answer is `max(finish)`; for the example it is 12. Time and space are `O(V+E)`.

## Q2 — Expected Waiting Time for HTH

### Question

Repeatedly flip a fair coin until HTH first appears. Derive the expected number of flips.

### Answer and Feedback

- Result: **Y/G**. The state-recursion approach was basically correct.
- The sole substantive error was transition bookkeeping: from suffix `HT`, a T returns to the empty state, so `E_HT = 1 + (1/2)0 + (1/2)E_0`.
- Correct answer: **10 flips**.

### Retrieval Cue

Use states for the longest suffix that is also a prefix of HTH: empty, H, and HT. Self-overlap matters because after `H + H`, the useful suffix remains H.

## Q5 — Time-Series Validation and Ridge

### Question

A next-day Treasury-return model uses 30 highly correlated lagged features. Randomly shuffled five-fold cross-validation looks excellent, but subsequent-month deployment fails. Explain two misleading-validation mechanisms, redesign validation, and choose Ridge or LASSO.

### Answer and Feedback

- Result: **P/Y**. Correctly preferred rolling validation and Ridge.
- “Future leakage” was directionally right but too generic. Interview-ready mechanisms include temporal leakage from random shuffling, regime / covariance shift, and dependence from overlapping or serially correlated observations.
- Ridge rationale should be coefficient stability under multicollinearity: L2 shrinkage distributes weight across correlated predictors instead of allowing unstable winner-take-one selection. Prefer LASSO when sparsity or interpretability is central.

## Q6 — Competing Poisson Processes

### Question

Independent Poisson processes have rates 2 and 3 per hour. Find (a) the probability the first A event occurs before the second B event and (b) the expected time to the first event of either process.

### Answer and Feedback

- Part (a): **M/P**. Guessed 4/7 by treating the second B event as exponential with rate 1.5. The second arrival time is Erlang / Gamma, not exponential.
- Part (b): **G**. Correctly used superposition rate 5, giving expected wait **1/5 hour**.

### Retrieval Cue

In the merged process, each arrival is labeled A with probability 2/5 and B with probability 3/5. A arrives before the second B if the first label is A, or the first is B and the second is A:

`2/5 + (3/5)(2/5) = 16/25`.
