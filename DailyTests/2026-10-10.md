## Q1 — Incremental Connectivity

### Question

Start with up to 200,000 isolated machines and process up to 200,000 undirected edges. After each edge, return the total number of unordered connected pairs. Duplicate edges and self-loops are allowed. Implement runnable Python 3 `connected_pairs(n, edges)`; justify correctness, complexity and tests. For `n=4`, `[(0,1),(1,2),(2,3),(0,3)]` gives `[1,3,6,6]`.

### Key solution

Maintain one global total. Joining distinct components of sizes $`a,b`$ creates exactly the cross-component pairs:

```math
\binom{a+b}{2}-\binom a2-\binom b2=ab.
```

```python
def connected_pairs(n, edges):
    parent = list(range(n))
    size = [1] * n
    total = 0
    result = []

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    for u, v in edges:
        a, b = find(u), find(v)
        if a != b:
            if size[a] < size[b]:
                a, b = b, a
            total += size[a] * size[b]
            parent[b] = a
            size[a] += size[b]
        result.append(total)
    return result
```

For $`m`$ edges: time $`O(n+m\alpha(n))`$, auxiliary space $`O(n)`$, output $`O(m)`$. Union by size keeps tree height logarithmic; path halving makes lookup amortized nearly constant.

### Review focus

**Weak point (I):** update the global total and always merge distinct roots; compare component sizes, not root labels. Reproduce the invariant on duplicate/self edges and separate components. The original final rewrite was unverified; a later [October 14 retest](2026-10-14.md#q1--connected-pairs) verified corrected runnable code.

## Q2 — Random Permutation Fixed Points

### Question

Six labeled envelopes are assigned uniformly to six owners. Let $`F`$ count correct returns. Derive $`P(F=0)`$, $`E[F]`$, $`\mathrm{Var}(F)`$ and $`E[F\mid F\gt0]`$ without enumeration code.

### Key solution

Inclusion-exclusion counts assignments fixing a specified subset; indicators give the moments:

```math
P(F=0)=\sum_{k=0}^6\frac{(-1)^k}{k!}=\frac{53}{144},\qquad
F=\sum_{i=1}^6 I_i.
```

```math
P(I_i=1)=\frac16,\quad P(I_i=I_j=1)=\frac1{30},\quad
\mathrm{Cov}(I_i,I_j)=\frac1{180}\quad(i\ne j).
```

```math
E[F]=1,\qquad
\mathrm{Var}(F)=6\frac16\frac56+2\binom62\frac1{180}=1,\qquad
E[F\mid F\gt0]=\frac{E[F]}{P(F\gt0)}=\frac{144}{91}.
```

### Review focus

**Weak point:** finish inclusion-exclusion through the final term; expectation linearity does not require independence, but variance needs covariance. The conditional-expectation identity was independently recognized. Rebuild from the [indicator cookbook](../KnowledgeCards/Probability/Indicator_Random_Variables_Cookbook.md); [October 14 R1](2026-10-14.md#r1--fixed-points) remains the priority retest.

## Q3 — Exact Randomization and A/B Testing

### Question

Exactly three of six units are randomly assigned treatment, with no interference. Outcomes are `[1,2,3,4,7,9]`; the last three units are treated. Under zero effect for every unit, find the exact two-sided p-value for treated-minus-control mean, including ties. Decide at 5%, explain exactness without normality, and assess a zero-average-effect null.

### Key solution

The sharp null fixes every potential outcome under reassignment:

```math
Y_i(1)=Y_i(0),\qquad T_{\mathrm{obs}}=\frac{14}{3},\qquad
N_{\mathrm{assignments}}=\binom63=20.
```

Only treated sets $`\{4,7,9\}`$ and $`\{1,2,3\}`$ are at least as extreme:

```math
p=\frac{2}{20}=0.10.
```

Fail to reject at 5%. Exactness comes from the known random assignment distribution. Zero average effect allows heterogeneous individual effects, so it does not identify all missing potential outcomes; the same fixed-outcome permutation test is not automatically exact for that weaker null.

### Review focus

**Knowledge gap (K):** assignment-based inference and sharp versus average-effect nulls. Independently enumerate a small assignment distribution, then review the [A/B checklist](../Backlog.md#ab-testing--review-to-do). Guided explanation has not established mastery.

## Q4 — Edit Distance

### Question

Return the minimum unit-cost insertions, deletions or replacements to transform `source` into `target`. No swaps; empty strings allowed; each length at most 2,000. Implement `min_changes`, explain complexity and test. Examples: `cat → cut` costs 1, empty → `abc` costs 3, `ab → ba` costs 2.

### Key solution

Use prefix lengths as states, with empty-prefix boundaries:

```math
D_{0,j}=j,\quad D_{i,0}=i,\qquad
D_{i,j}=\min\left\{D_{i-1,j}+1,\ D_{i,j-1}+1,\ D_{i-1,j-1}+\mathbf1\{s_i\ne t_j\}\right\}.
```

```python
def min_changes(source, target):
    n, m = len(source), len(target)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        dp[i][0] = i
    for j in range(m + 1):
        dp[0][j] = j
    for i in range(n):
        for j in range(m):
            if source[i] == target[j]:
                dp[i + 1][j + 1] = dp[i][j]
            else:
                dp[i + 1][j + 1] = 1 + min(
                    dp[i + 1][j],  # insertion
                    dp[i][j + 1],  # deletion
                    dp[i][j],      # replacement
                )
    return dp[n][m]
```

Time and space $`O(nm)`$; two rolling rows reduce auxiliary space to $`O(\min(n,m))`$.

### Review focus

**Implementation gap (I):** distinguish prefix lengths from character indices, allocate the empty row/column, include all three transitions, and return the full-prefix state. DP direction and empty-prefix boundaries were independent. A complete independent rewrite remains unverified.

## Q5 — Tree Extrapolation

### Question

Train a standard mean-leaf random forest on $`x\in[0,1]`$ with $`Y=2+3x+\varepsilon`$, $`E[\varepsilon\mid x]=0`$. Deploy on $`[1.2,1.5]`$. Describe predictions, whether more trees help, and a model change plus evaluation experiment.

### Key solution

With one feature, all points beyond the training splits enter the same leaf in each tree, so the forest is constant across this deployment interval. More trees do not create linear extrapolation. Fit OLS and the forest on the training range, then compare test MAE on independent labeled deployment-range data. A lower-range/higher-range split is only a stress test if actual deployment labels are unavailable.

### Review focus

**Weak point:** use out-of-sample data matching deployment; training error and random in-range splits do not test extrapolation. Tree limitations and the OLS alternative were independently understood. [Related validation note](../Questions/TimeSeries/T007_Random_Forest_Rates_Signals_and_Time_Series_Validation.md).

## Q6 — Finite-Horizon Optimal Stopping

### Question

Up to three independent $`\mathrm{Uniform}(0,1)`$ draws. First draw free; each redraw costs 0.10 and permanently discards the previous draw. Third draw must be accepted; no recall. Find the optimal policy, expected net payoff and expected draw count.

### Key solution

Work backward. Accept the third draw. Redraw the second below 0.4; the value before seeing the second is:

```math
V_2=0.6(0.7)+0.4(0.5-0.1)=0.58.
```

Redraw the first below $`V_2-0.1=0.48`$:

```math
V_1=0.48(0.58-0.1)+0.52\frac{0.48+1}{2}=0.6152,
\qquad E[N]=1+0.48+0.48(0.4)=1.672.
```

### Review focus

**Weak point:** include remaining optionality and future costs in continuation value; distinguish stopping probability from the probability of reaching the next draw. The second-draw threshold was independent. Reproduce backward induction and the tail-sum draw count.

## Q7 — Interaction and Recentering

### Question

A full-rank unpenalized fit is $`\widehat Y=2+0.8X+0.3Z-0.04XZ`$. Does increasing $`X`$ always raise predictions? Set $`W=Z-10`$; rewrite the fit, assess fitted values/RSS, and compare old/new tests of the main $`X`$ coefficient against zero.

### Key solution

```math
\frac{\partial\widehat Y}{\partial X}=0.8-0.04Z,\qquad
\widehat Y=5+0.4X+0.3W-0.04XW.
```

Fitted values and RSS are unchanged, but main effects refer to different reference levels:

```math
H_{0,\mathrm{old}}:\beta_X=0,\qquad
H_{0,\mathrm{new}}:\beta_X+10\beta_{XZ}=0.
```

```math
\mathrm{Var}(\hat\beta_X+10\hat\beta_{XZ})
=\mathrm{Var}(\hat\beta_X)+100\mathrm{Var}(\hat\beta_{XZ})
+20\mathrm{Cov}(\hat\beta_X,\hat\beta_{XZ}).
```

### Review focus

**Weak point:** substitute the shift in the correct direction and retain covariance when transforming coefficient uncertainty. The derivative, invariant fit and distinction between the two hypotheses were independently understood.

## Q8 — Gradient Descent and Spectral Contraction

### Question

For $`f(w)=\tfrac12w^\top Hw`$, let $`H`$ be symmetric positive definite with extreme eigenvalues 2 and 18. Find constant gradient-descent steps guaranteeing convergence from every start, assess $`\eta=0.12`$, and minimize worst-direction Euclidean contraction.

### Key solution

```math
\nabla f(w)=Hw,\quad w_{k+1}=(I-\eta H)w_k,\quad
\left|1-\eta\lambda_i\right|\lt1\iff 0\lt\eta\lt\frac{2}{18}.
```

The proposed step fails in the largest-eigenvalue direction. Balance the endpoint magnitudes for the optimal step:

```math
1-2\eta=18\eta-1\quad\Longrightarrow\quad
\eta^*=0.1,\qquad q^*=0.8.
```

### Review focus

**Knowledge gap (K):** negative gradient, step-size overshoot, eigen-direction multipliers and minimax contraction. First derive one-dimensional stability; the original 3-minute cap was not a realistic first-learning budget.
