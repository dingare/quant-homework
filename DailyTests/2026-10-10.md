## Q1 — Incremental Connectivity

### Question

Start with n isolated machines numbered 0 through n-1. Undirected edges arrive and remain active; duplicate edges and self-loops are allowed. After each arrival, return the total number of unordered pairs of distinct machines connected directly or indirectly. Implement `connected_pairs(n, edges)` for up to 200,000 machines and 200,000 arrivals; justify correctness, complexity, and tests. Example: n=4, edges=[(0,1),(1,2),(2,3),(0,3)] gives [1,3,6,6].

### Independent Attempt and Feedback

- User reported **12 minutes** for the initial set-based attempt, exceeding the 11-minute cap. Input clarification was not counted as an algorithm hint.
- Maintained full member sets and propagated updates to members. Recognized that updating every child was inefficient.
- Counted only the component touched by the new edge. With n=4 and edges=[(0,1),(2,3)], returned [1,1] instead of [1,2]. `/` also produced floats instead of integer counts.
- Worst-case bound for that implementation is O(m n^2) time and O(n^2) auxiliary space: each arrival can trigger n set updates each touching n entries.
- DSU, root pointers, union by size, path halving, and the a*b increment were explained afterward.
- User independently rewrote `find_root` after the explanation. Their union compared root IDs and only executed for one ordering; count could increase without a merge. Corrected union logic was supplied. User said they rewrote to fix it, but no final corrected implementation was submitted for verification.

### Worked Reference — Supplied After Attempt

Merging different components of sizes a and b adds exactly a*b new cross-component pairs. Same-root edges add zero. A parent pointer represents membership, not necessarily a physical network edge. Union changes one root pointer; members need not be individually relabeled.

```python
def connected_pairs(n, edges):
    parent = list(range(n))
    size = [1] * n
    total = 0
    result = []

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x

    for u, v in edges:
        a, b = find(u), find(v)
        if a != b:
            if size[a] < size[b]:
                a, b = b, a
            total += size[a] * size[b]
            parent[b] = a
            size[a] += size[b]
        result.append(total)
    return result
```

Time O(n + m alpha(n)); auxiliary space O(n), plus O(m) output. Path halving skips to a grandparent during lookup; omitting it does not break correctness. Union by size still prevents long-chain degeneration, with O(log n) worst-case lookup without compression.

## Q2 — Random Permutation Fixed Points

### Question

Six labeled envelopes are returned to their six owners via a uniform random permutation. Let F count correct returns. Derive exact P(F=0), E[F], Var(F), and E[F | F>0], without code enumeration.

### Independent Attempt and Feedback

- Initial **9 minutes** spent only on part 1 using brute-force reasoning by numbers of fixed points. Corrected their reported attempt to `1 - 226/6!`; this was still incorrect.
- Requested a hint. After inclusion-exclusion was suggested, produced the alternating sum but omitted the k=6 term.
- Considered computing the whole distribution for moments, then said indicators had occurred to them but dependence was confusing.
- Correctly identified the marginal variance (1/6)(5/6). Needed the pairwise conditional probability and explanation that expectation linearity does not require independence.
- Concern: five correct returns and one incorrect return are impossible. Clarification: the six indicators are read from one permutation, not generated independently; impossible joint outcomes have probability zero.
- Independently proposed the total-expectation identity for part 3 after the earlier guided discussion. This subpart reasoning was correct; the whole question remains hinted.

### Worked Reference

For a specified set of k owners, all are correct in (6-k)! permutations. Summing over choices gives binom(6,k)(6-k)!/6! = 1/k!.

```math
P(F=0)=\sum_{k=0}^{6}\frac{(-1)^k}{k!}=\frac{265}{720}=\frac{53}{144}.
```

With F=sum I_i, each I_i is Bernoulli(1/6), and for i != j,

```math
E[F]=1,\qquad P(I_i=I_j=1)=\frac16\frac15=\frac1{30},
\qquad \mathrm{Cov}(I_i,I_j)=\frac1{180}.
```

```math
\mathrm{Var}(F)=6\frac16\frac56+2\binom62\frac1{180}=1.
```

Linearity of expectation holds without independence; covariance is needed for variance. Specifying five owners as correct allows all six to be correct, even though exactly five correct is impossible.

```math
E[F]=E[F\mid F>0]P(F>0)+0,\qquad E[F\mid F>0]=\frac{144}{91}.
```

## Q3 — Exact Randomization and A/B Testing

### Question

Exactly three of six units are assigned treatment uniformly; no interference. Outcomes are [1,2,3,4,7,9], and the last three units are treated. Use treated mean minus control mean. Under zero treatment effect for every unit, calculate the exact two-sided randomization p-value including ties, decide at 5%, explain exactness without normality, and assess whether it extends automatically to a zero-average-effect null.

### Independent Attempt and Feedback

- Correct observed difference, 20/3 - 2, but divided by an unsupported standard error and proposed sample-variance reasoning.
- Said reject, attributed exactness to sample variance, and said the average-effect null works the same way.
- **Miss, explicitly confirmed by user. Knowledge gap:** user had not previously encountered this type of question and requested A/B testing review.
- Explanations below were taught afterward; do not record as a cold solution.

### Worked Reference and Review Notes

Under the sharp null, every unit has Y_i(1)=Y_i(0), so outcomes remain fixed under reassignment. There are binom(6,3)=20 equally likely assignments. Observed T=14/3. Only treated sets {4,7,9} and {1,2,3} have |T| at least 14/3. Thus p=2/20=0.10; fail to reject at 5%.

Exactness comes from the known assignment distribution under the sharp null, not normality or a sample variance estimate. A zero-average-effect null allows heterogeneous effects that cancel; it does not impute all missing potential outcomes, so fixed-outcome reassignment does not automatically provide an exact test of that weaker null.

An individual effect is Y_i(1)-Y_i(0); generally only one potential outcome is observed. Under complete randomization, difference in group means is unbiased for the finite-population average effect. A/B testing is experimental design; randomization tests, Welch tests, and proportion tests are different analysis choices with different assumptions. Distinguish effect size and uncertainty from practical value.

## Q4 — Edit Distance

### Question

Transform source into target with unit-cost insertion, deletion, or replacement, returning minimum cost. No swaps. Empty strings allowed; lengths at most 2,000. Implement `min_changes(source, target)`, explain complexity, and test. Examples: cat -> cut = 1; empty -> abc = 3; ab -> ba = 2.

### Independent Attempt and Feedback

- Independently proposed DP, recognizing that insertion/deletion shift alignment, but could not define the state/transition clearly.
- Prefix-length state was supplied. User understood O(nm) time/space and correctly gave dp[0][j]=j and dp[i][0]=i.
- Initial transitions mixed character indices and prefix lengths, omitted replacement, and treated candidate transitions as unconditional minima.
- Submitted implementation allocated n by m instead of (n+1) by (m+1), stopped loops at n-2/m-2, incompletely initialized boundaries inside the main loop, duplicated the deletion predecessor instead of including insertion, and returned dp[i][j] rather than dp[n][m]. Empty inputs also leave loop variables undefined.
- Corrected complete implementation was supplied; no subsequent user implementation verified. Result remains Partial / Hinted with clear I gaps.

### Worked Reference — Supplied After Attempt

dp[i][j] = minimum cost to convert the first i source characters to the first j target characters. Empty-prefix boundaries count required insertions/deletions.

```python
def min_changes(source, target):
    n, m = len(source), len(target)
    dp = [[0] * (m + 1) for _ in range(n + 1)]
    for i in range(n + 1):
        dp[i][0] = i
    for j in range(m + 1):
        dp[0][j] = j
    for i in range(n):
        for j in range(m):
            if source[i] == target[j]:
                dp[i + 1][j + 1] = dp[i][j]
            else:
                dp[i + 1][j + 1] = 1 + min(
                    dp[i + 1][j],  # insertion
                    dp[i][j + 1],  # deletion
                    dp[i][j],      # replacement
                )
    return dp[n][m]
```

O(nm) time and O(nm) space; rolling rows can reduce auxiliary space to O(min(n,m)). This optimization was discussed, not implemented by the user.

### Question

Train a standard random forest with mean-response leaves on x in [0,1], with true model Y=2+3x+epsilon and E[epsilon | x]=0. Deploy on [1.2,1.5]. Describe predictions across that interval, whether more trees fix the issue, and a model change plus concrete evaluation experiment.

- When asked for evaluation, proposed random train/test splitting and training MAE. This misses deployment-range extrapolation and out-of-sample evaluation.
- Core mechanism/model choice independently correct; evaluation design was supplied afterward. Partial / Hinted.

### Worked Reference

With one feature and standard training-range splits, all x>1 route to the same terminal leaf within each tree; the forest is constant over the deployment interval. The prediction need not equal the true mean 5 at x=1. More trees cannot change this structural extrapolation limit.

Fit OLS and the forest using only [0,1]; compare test MAE on independent labeled [1.2,1.5] data and inspect prediction curves. If those labels are unavailable, lower-range training / higher-range testing is a stress test, not proof of deployment performance. OLS is appropriate here because the specified conditional mean is linear.

### Question

Up to three independent Uniform(0,1) draws. First draw free; after either of the first two, keep and stop or pay 0.10 to discard permanently and redraw. Third draw mandatory acceptance; no recall. Find optimal policy, expected net payoff before the first draw, and expected number of draws.

- Recognized backward induction as analogous to an option after guidance. Then correctly obtained the first threshold 0.48.
- Payoff expression confused 0.1 cost with 1 and the stopping probability 0.52 with the conditional interval lower bound 0.48; arithmetic structure was corrected.
- For draw counts used 0.52 rather than 0.48, confusing stop and continue probabilities, and used expectation notation for event probabilities.
- Partial / Hinted. Post-explanation understanding is not independent mastery evidence.

### Worked Reference

Third draw: accept. Second draw: continue below 0.4, stop above. Before the second draw, excluding past costs,

```math
V_2=0.6(0.7)+0.4(0.5-0.1)=0.58.
```

First draw: continue below V_2-0.1=0.48. Ties are indifferent and have probability zero.

```math
V_1=0.48(0.58-0.1)+0.52\frac{0.48+1}{2}=0.6152.
```

```math
E[N]=1+P(N\ge2)+P(N\ge3)=1+0.48+0.48(0.4)=1.672.
```

Past costs are sunk for the current decision; future costs must be included in continuation value. Finite-horizon decision recursion differs from the recent fixed-pattern absorption recursions.

- Partial; actual time not recorded.

### Worked Reference

```math
\widehat Y=5+0.4X+0.3W-0.04XW.
```

The effect of X is zero at Z=20 and changes sign there. Recentering leaves the fitted model unchanged but changes the reference value for the X main effect.

Old null: beta_X=0, effect at Z=0. New null: beta_X+10 beta_XZ=0, effect at Z=10. The estimator variance generally changes:

```math
\mathrm{Var}(\hat\beta_X+10\hat\beta_{XZ})
=\mathrm{Var}(\hat\beta_X)+100\mathrm{Var}(\hat\beta_{XZ})
+20\mathrm{Cov}(\hat\beta_X,\hat\beta_{XZ}).
```

Testing the same hypothesis expressed consistently in either parameterization must give the same result; these two coefficient-zero tests are different hypotheses.

## Q8 — Gradient Descent and Spectral Contraction

### Question

For f(w)=0.5 w^T H w, H symmetric positive definite with extreme eigenvalues 2 and 18, use w_(k+1)=w_k-eta grad f(w_k). Find constant step sizes guaranteeing convergence from every start, assess eta=0.12, and find the step minimizing worst-case Euclidean error contraction.

### Independent Attempt and Feedback

- User explicitly said they did not know how to answer and were unfamiliar: **Miss / K**.
- Subsequent teaching covered the local linear approximation, negative gradient, gradient Hw, identity-matrix factoring, eigen-direction multipliers, strict convergence bounds, and the minimax objective.
- Clarified that 2/18 is an excluded upper bound, not the recommended step; 1/18 is valid but conservative for the worst-direction objective.
- Needed explanation of what part 3 asks and why the endpoint magnitudes are equated. Eventually understood it as minimizing q(eta).
- Original 3-minute cap is suitable for retrieval after prior study, not learning these foundations from scratch. User accepted retaining unfamiliar material and the broad drill style. Exact optimal-step derivation is an advanced follow-up, not asserted to be universally high-frequency in quant interviews.

### Worked Reference

The local approximation is f(w+delta)-f(w) approximately grad f(w)^T delta. Choosing delta=-eta grad f(w) makes this -eta ||grad f(w)||^2, negative for nonzero gradient. Sufficiently small steps decrease a smooth objective; oversized steps can overshoot.

For this quadratic, grad f(w)=Hw and w*=0, hence

```math
w_{k+1}=(I-\eta H)w_k.
```

Each eigen-direction is multiplied by 1-eta lambda. Convergence from every start requires |1-eta lambda|<1 for every eigenvalue:

```math
0<\eta<\frac{2}{18}=\frac19.
```

At eta=0.12 the largest-eigenvalue multiplier is -1.16, so there is no all-start convergence guarantee. At eta=2/18 it is -1 and does not shrink. Negative multipliers with magnitude below one oscillate while converging.

```math
q(\eta)=\max\{|1-2\eta|,|1-18\eta|\}.
```

For eta up to 1/18, q=1-2 eta decreases. Between 1/18 and 1/9, q=max(1-2 eta,18 eta-1), the maximum of a decreasing and an increasing line. Its minimum is their intersection, not an unsupported assumption that the multipliers must always have opposite signs:

```math
1-2\eta=18\eta-1\quad\Rightarrow\quad\eta^*=0.1,\qquad q^*=0.8.
```

All intermediate eigenvalues also have multiplier magnitude at most 0.8 at this step.
