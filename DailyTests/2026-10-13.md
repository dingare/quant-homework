## Q1 — Arithmetic Expressions and Nested State

### Question

Implement runnable Python 3 `evaluate(expression: str) -> int` for valid expressions containing nonnegative integer literals, `+`, `-`, parentheses and whitespace. Consecutive unary signs are allowed; whitespace never splits a literal. Up to 200,000 characters with deep nesting; no `eval`, parsing libraries or recursion-limit changes. Assume constant-cost integer arithmetic. Explain correctness/complexity and run four distinct edge tests.

Examples: `1 - (2 - (3 + 4))` gives 6; `-(-3 + 2) - 4` gives -3; `1--2` gives 3. **Pending follow-up:** how must the representation change for multiplication precedence? No extra implementation required.

### Key solution

Keep a current total, next-operand sign and whether an operand is expected. A stack saves each outer total and connecting sign; closing a parenthesis folds the inner total back into its parent.

```python
def evaluate(expression: str) -> int:
    stack = []
    total = 0
    sign = 1
    expecting_operand = True
    i = 0

    while i < len(expression):
        s = expression[i]
        if s.isspace():
            i += 1
            continue

        if s.isdigit():
            num = 0
            while i < len(expression) and expression[i].isdigit():
                num = num * 10 + int(expression[i])
                i += 1
            total += sign * num
            sign = 1
            expecting_operand = False
            continue

        if s in '+-':
            if expecting_operand:
                sign *= 1 if s == '+' else -1
            else:
                sign = 1 if s == '+' else -1
                expecting_operand = True

        if s == '(':
            stack.append((total, sign))
            total = 0
            sign = 1
            expecting_operand = True

        if s == ')':
            outer_total, outer_sign = stack.pop()
            total = outer_total + outer_sign * total
            expecting_operand = False

        i += 1

    return total
```

Each character is scanned once: time $`O(n)`$, auxiliary space $`O(d)`$ for maximum nesting depth $`d`$.

### Review focus

**Implementation gap (I):** advance past whitespace, convert digits to integers, and avoid skipping the next token after a number. Distinguish unary sign flipping from binary sign assignment and preserve nested scope. ## Q2 — Random Inspection and Remaining Wait

### Question

A continuous service has iid intervals of 1 or 9 minutes, equally likely. Inspect at an independent uniform time over a long observation window. Find the probability of being in a 9-minute interval, expected residual wait, and probability that residual wait exceeds 4 minutes. Compare with starting immediately after a completion.

### Key solution

First select the interval by time share, then use uniform position within that interval:

```math
P(L=9)=\frac{(1/2)9}{(1/2)1+(1/2)9}=0.9,\qquad
R\mid L=\ell\sim\mathrm{Uniform}(0,\ell).
```

```math
E[R]=0.9\frac92+0.1\frac12=4.1,\qquad
P(R\gt4)=0.9\frac59=0.5.
```

Starting at a completion gives the full next interval, with mean 5 minutes and no length bias.

### Review focus

**Weak point:** residual-tail probability must include position inside the selected interval. Interval weighting, residual mean and completion-start comparison were independent; the clarified decimal typo is not a conceptual error. ## Q3 — Product Distribution and Event Conditioning

### Question

Let $`U,V`$ be independent $`\mathrm{Uniform}(0,1)`$ variables and $`Z=UV`$. Derive the CDF and density, including domains. Find $`E[U\mid UV\gt1/2]`$ without simulation and decide whether $`U,V`$ remain independent after conditioning.

### Key solution

Clip the integration region at the unit-square boundary:

```math
F_Z(z)=\begin{cases}
0,&z\le0,\\
z-z\ln z,&0\lt z\lt1,\\
1,&z\ge1,
\end{cases}
\qquad
f_Z(z)=-\ln z\quad(0\lt z\lt1).
```

The density is zero outside this interval. For $`A=\{UV\gt1/2\}`$:

```math
P(A)=\frac{1-\ln2}{2},\qquad
E[U\mathbf1_A]=\int_{1/2}^1\int_{1/(2u)}^1u\,dv\,du=\frac18,
\qquad E[U\mid A]=\frac{1}{4(1-\ln2)}.
```

Either integration order is valid with matching bounds. Under $`A`$, the conditional support of $`V`$ given $`U=u`$ is $`(1/(2u),1)`$, so dependence follows. The requested covariance check is:

```math
E[UV\mid A]=\frac{3-2\ln2}{8(1-\ln2)},\qquad
\mathrm{Cov}(U,V\mid A)=\frac{3-2\ln2}{8(1-\ln2)}-\frac{1}{16(1-\ln2)^2}\approx-0.006412.
```

### Review focus

**Weak point:** clip support, divide event-weighted moments by event probability, and condition every covariance term on the same event. The reversed inequality was a reading slip; the user's integration order and clarified numerator $`1/8`$ were valid. Independently reconstruct the conditional mean and support argument.

## Q4 — Ratio-of-Means Inference

### Question

Observe iid pairs $`(X_i,Y_i)`$ with $`Y_i\gt0`$, finite second moments and $`\mu_Y=E[Y_i]\gt0`$:

```math
r=\frac{E[X_i]}{E[Y_i]},\qquad\hat r=\frac{\bar X}{\bar Y}.
```

Derive the limiting distribution of $`\sqrt n(\hat r-r)`$, an implementable approximate 95% CI and a nondegeneracy condition. Does averaging individual ratios estimate the same target? Give a counterexample with finite targets, and explain why denominator uncertainty can undermine the interval.

### Key solution

Center before applying CLT; use denominator convergence and Slutsky:

```math
W_i=X_i-rY_i,\quad E[W_i]=0,\quad
\hat r-r=\frac{\bar W}{\bar Y},\quad
\sqrt n(\hat r-r)\xrightarrow{d}N\!\left(0,\frac{\sigma_W^2}{\mu_Y^2}\right).
```

Require $`\sigma_W^2\gt0`$ and retain within-pair covariance:

```math
\sigma_W^2=\mathrm{Var}(X_i)+r^2\mathrm{Var}(Y_i)-2r\,\mathrm{Cov}(X_i,Y_i).
```

```math
s_W^2=\frac1{n-1}\sum_i(X_i-\hat rY_i)^2,\qquad
\widehat{\mathrm{SE}}(\hat r)=\frac{s_W}{\sqrt n\,\bar Y},\qquad
\mathrm{CI}_{0.95}:\ \hat r\pm z_{0.975}\frac{s_W}{\sqrt n\,\bar Y}.
```

This is asymptotic, not an exact t interval. A denominator small relative to its sampling uncertainty can create asymmetric ratio behavior and poor Wald coverage; small units alone are not the issue.

With integrable individual ratios, their average targets $`E[X/Y]`$. For $`X\equiv1`$ and $`Y\sim\mathrm{Uniform}(1,3)`$:

```math
E[X/Y]=\frac12\int_1^3\frac1y\,dy=\frac{\ln3}{2}
\ne\frac{E[X]}{E[Y]}=\frac12.
```

The original second-moment assumptions alone do not guarantee integrability of individual ratios.

### Review focus

**Weak point:** transform to a centered CLT, convert limiting fluctuation variance to estimator SE, retain density normalization in examples, and explain relative denominator uncertainty. Plug-in intuition and the uniform counterexample idea were independent; the full derivation was guided.

## Q5 — Deployment Probabilities and Decisions

### Question

A binary classifier returns the exact calibrated training posterior $`p_{\mathrm{train}}(x)=P_{\mathrm{train}}(Y=1\mid X=x)`$. Training prevalence is 0.5, deployment prevalence 0.1, and class-conditional feature distributions $`P(X\mid Y)`$ remain unchanged. Derive the deployment probability and evaluate training output 0.8.

**Pending follow-up:** false positives cost 1, false negatives cost 9, correct decisions cost zero. Derive the optimal rule in terms of the training output and explain why threshold adjustment alone does not recalibrate reported probabilities.

### Key solution

For class prevalence $`\pi`$ and unchanged class-conditional densities $`f_1,f_0`$:

```math
\frac{P(Y=1\mid x)}{P(Y=0\mid x)}=\frac{f_1(x)}{f_0(x)}\frac{\pi}{1-\pi}.
```

Only the prior-odds factor changes:

```math
\frac{p_{\mathrm{deploy}}}{1-p_{\mathrm{deploy}}}
=\frac{0.1/0.9}{0.5/0.5}\frac{p_{\mathrm{train}}}{1-p_{\mathrm{train}}}
=\frac19\frac{p_{\mathrm{train}}}{1-p_{\mathrm{train}}},\qquad
p_{\mathrm{deploy}}=\frac{p_{\mathrm{train}}}{9-8p_{\mathrm{train}}}.
```

At training output 0.8, the deployment probability is $`4/13\approx0.307692`$. The multiplier applies to odds, not directly to probability. The decision follow-up has no published solution yet.

### Review focus

**Weak point:** distinguish prior, likelihood, posterior, probability and odds; independently convert adjusted odds back to probability. Main question reviewed with assistance. Complete the original follow-up without an initial hint.
