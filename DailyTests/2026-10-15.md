## Q1 — Median of Two Sorted Arrays

### Question

Implement runnable Python 3 `combined_median(a, b) -> float` for two sorted integer arrays. Either may be empty, but their combined length is positive. Negative values and duplicates are allowed; do not modify the inputs, merge the arrays, or sort their combined contents. Target logarithmic time in the shorter array length and constant auxiliary space. Explain correctness/complexity and test empty arrays, unequal lengths and duplicates.

Examples: `[1,3]`, `[2]` gives 2.0; `[1,2]`, `[3,4]` gives 2.5; `[]`, `[-5,-1]` gives -3.0; `[1,1,1]`, `[1,2]` gives 1.0.

### Key solution

The user's independent approach partially merged the arrays until the median ranks. This can yield a correct linear-time solution, but does not meet the logarithmic target. If `p` values have been consumed and `i`/`j` point to the next unconsumed values, global one-based rank `k` is offset `k - p - 1` into the surviving suffix. When neither median has been collected, skip values before the lower median before collecting the two central values.

For the target solution, binary-search the partition of the shorter array. If its left side contains `i` elements, the other array contributes `j = left_size - i`.

```math
L=\left\lfloor\frac{m+n+1}{2}\right\rfloor,\qquad i+j=L.
```

Within-array ordering already holds. A valid partition only needs the two cross-boundary comparisons:

```math
a_{i-1}\le b_j,\qquad b_{j-1}\le a_i.
```

Treat empty left/right boundaries as negative/positive infinity. If the first comparison fails, decrease `i`; if the second fails, increase `i`. These failures remain failures farther in the wrong direction. At a valid partition, take the maximum left boundary for odd total length; average the maximum left and minimum right boundaries for even total length.

```python
def combined_median(a, b):
    if len(a) > len(b):
        a, b = b, a
    m, n = len(a), len(b)
    if m + n == 0:
        raise ValueError("At least one array must be nonempty")

    left_size = (m + n + 1) // 2
    lo, hi = 0, m
    while lo <= hi:
        i = (lo + hi) // 2
        j = left_size - i
        a_left = a[i - 1] if i > 0 else float("-inf")
        a_right = a[i] if i < m else float("inf")
        b_left = b[j - 1] if j > 0 else float("-inf")
        b_right = b[j] if j < n else float("inf")

        if a_left <= b_right and b_left <= a_right:
            if (m + n) % 2:
                return float(max(a_left, b_left))
            return (max(a_left, b_left) + min(a_right, b_right)) / 2.0
        if a_left > b_right:
            hi = i - 1
        else:
            lo = i + 1
    raise ValueError("Inputs must be sorted")
```

Time is logarithmic in the shorter array length, with constant time when it is empty; auxiliary space is constant. Rebinding `a, b` does not mutate inputs.

## Q2 — Exact Uniform Sampling from an Unknown Biased Coin

### Question

You have independent coin flips with fixed unknown heads probability $`p\in(0,1)`$. Without estimating/querying $`p`$ or using other randomness, design an algorithm returning an exactly uniform integer from $`\{0,1,\ldots,6\}`$. Give precise pseudocode, prove uniformity and almost-sure termination, derive expected raw flips as a function of $`p`$, and discuss both endpoint limits. Repeated calls must produce independent outputs.

### Key solution

User's valid construction: fix seven distinct ordered six-flip patterns containing exactly three heads and three tails; map them one-to-one to outputs 0–6. Toss independent six-flip blocks. Return the matching output for a selected pattern, otherwise discard the entire block and retry. Fresh calls continue with fresh independent flips.

```math
\binom63=20,\qquad
P(\text{one selected pattern})=p^3(1-p)^3,\qquad
q=P(\text{accepted block})=7p^3(1-p)^3.
```

Conditional on acceptance, each output has probability one seventh. Equivalently, summing over rejected blocks gives the unconditional output probability:

```math
P(\text{output}=r)=\sum_{k=0}^{\infty}(1-q)^k p^3(1-p)^3=\frac17.
```

```math
P(\text{no success in }N\text{ blocks})=(1-q)^N\longrightarrow0,
\qquad
E[\text{blocks}]=\frac1q,\qquad
E[\text{raw flips}]=\frac6q=\frac{6}{7p^3(1-p)^3}.
```

The expected raw-flip cost diverges at either endpoint; at a fair coin it is $`384/7\approx54.86`$. Independent blocks and restarting after a successful block yield independent outputs on repeated calls. No efficiency-optimality claim is made.

### Review focus

**Independent success:** equal-probability ordered-pattern rejection construction and the intuition that repeated failure tends to zero. The initial count 15 was explicitly clarified as a typo for 20; do not classify it as a combinatorics gap. **Weak point:** the proposed reciprocal omitted seven accepted patterns and the six-flips-per-block conversion. ## Q3 — Most-Powerful Testing for Increased Normal Variance

### Question

An anomaly detector observes one real measurement with hypotheses $`H_0:X\sim N(0,1)`$ and $`H_1:X\sim N(0,4)`$, where the second parameter is variance. Construct the most-powerful test with false-positive probability at most 5%, justify optimality and calculate power. Compare with rejecting when $`X\gt1.645`$. For two independent observations with the same distribution under each hypothesis, give the optimal rejection rule and power. Standard normal CDF expressions and named-distribution quantiles are acceptable.

### Key solution

**Logical sequence:** use the likelihood ratio to choose the rejection region's shape; use the null distribution to set its size; use the alternative distribution to calculate power. A rule is fixed before evaluating these two probabilities.

For two fully specified hypotheses, the Neyman–Pearson lemma selects the largest likelihood ratios. For a small region near an observation, alternative probability is the detection benefit, null probability is the false-positive cost, and their ratio gives benefit per unit cost. Swapping equally costly null-probability regions for higher-ratio regions increases power. The ratio compares the same observation under two hypotheses, not the densities of two different observations; it is not itself a probability or power.

```math
\Lambda(x)=\frac{f_1(x)}{f_0(x)}=\frac12e^{3x^2/8}.
```

This increases with absolute value, so the optimal region is two-sided. Let $`c=\Phi^{-1}(0.975)`$:

```math
P_0(|X|\gt c)=0.05,\qquad c\approx1.959964,
\qquad
\text{Power}=P_1(|X|\gt c)=2[1-\Phi(c/2)]\approx0.327095.
```

Under the alternative, standard deviation is 2, so $`Z=X/2\sim N(0,1)`$. Dividing the statistic and cutoff by 2 rewrites the same rejection event; the raw-data cutoff remains unchanged. The comparison rule has approximately 5% size and lower power:

```math
P_1(X\gt1.645)=1-\Phi(1.645/2)\approx0.205396.
```

For two independent observations, multiply the two likelihood ratios:

```math
S=X_1^2+X_2^2,\qquad
\Lambda(x_1,x_2)=\frac14e^{3S/8}.
```

Thus large squared distance from zero supports the higher-variance alternative; signed observations should not cancel. This is one joint test, not two separate 5% tests.

```math
S\mid H_0\sim\chi^2_2,\qquad
S/4\mid H_1\sim\chi^2_2,\qquad
c_2=\chi^2_{2,0.95}=-2\ln0.05\approx5.991465.
```

```math
\text{Reject }H_0\text{ when }S\gt c_2,\qquad
\text{Power}=P(\chi^2_2\gt c_2/4)=e^{-c_2/8}=0.05^{1/4}\approx0.472871.
```

The squared-sum rule is specific to this independent zero-mean normal variance comparison. More generally, reject for a large likelihood ratio; its level set may be one tail, two tails, a central interval or disconnected regions. Composite hypotheses with unknown parameters require additional work and do not automatically admit a test most powerful against every alternative. Boundary randomization can be needed for exact size in discrete models.

## Q4 — Feasible Correlations and Zero-Variance Portfolios

### Question

Three signals $`X,Y,Z`$ have mean zero and variance one, with correlations:

```math
\mathrm{Corr}(X,Y)=0.8,\qquad
\mathrm{Corr}(X,Z)=0.6,\qquad
\mathrm{Corr}(Y,Z)=r.
```

A colleague proposes $`r=-0.1`$, arguing that every pairwise correlation lies between negative one and one. Determine whether this proposal is coherent. Find the exact admissible range of $`r`$ and justify that every value in your range is attainable. At each endpoint, exhibit nonzero coefficients $`(a,b,c)`$ for which $`aX+bY+cZ`$ has zero variance.

### Status

**Mastered.** On October 16 the user confirmed independently solving the problem and understanding the underlying concepts: PSD correlation matrices, determinant constraints, singular covariance matrices, null space, and zero-variance portfolios. This supersedes the initial deferred/Pending status. Actual solving time was not reported.

### Key solution

The correlation matrix must be positive semidefinite:

```math
R(r)=\begin{pmatrix}
1&0.8&0.6\\
0.8&1&r\\
0.6&r&1
\end{pmatrix},\qquad
\det R(r)=0.96r-r^2=r(0.96-r).
```

The determinant constraint gives the admissible range below. All smaller principal minors are nonnegative throughout this range, so the constraint is also sufficient for PSD. Every such matrix is attainable as the covariance of a centered random vector, for example a possibly degenerate Gaussian vector. The proposed negative correlation is therefore inadmissible.

```math
\boxed{0\le r\le0.96}.
```

At both endpoints the covariance matrix is singular. The endpoint portfolios lie in its null space:

```math
\begin{aligned}
r=0:&\quad w_0=(-5,4,3)^\top,\qquad R(0)w_0=0,\\
r=0.96:&\quad w_{0.96}=(7,-20,15)^\top,\qquad R(0.96)w_{0.96}=0.
\end{aligned}
```

For portfolio weights in the null space, the variance is zero:

```math
\mathrm{Var}(aX+bY+cZ)=w^\top R(r)w=0.
```
