## Q1 — Shortest Route with One Blocked Entry

### Question

Implement runnable Python 3:

```python
def shortest_route(grid: list[list[int]]) -> int:
    ...
```

A nonempty rectangular grid contains open cells (0) and blocked cells (1). Start at the top-left cell and reach the bottom-right cell. Both endpoints are open. Each move goes up, down, left or right and costs one step. **At most one move during the entire route may enter a blocked cell.** Every other move must enter an open cell.

Return the minimum number of steps, or -1 if reaching the destination is impossible. There are at most 200,000 cells. Do not modify the input. Examples: `[[0,1],[1,0]]` returns 2; `[[0,1,1,0]]` returns -1; `[[0]]` returns 0.

Derive an $`O(RC)`$-time approach. Explain what information the algorithm retains, correctness and auxiliary space. Include runnable tests covering zero blocked entries, a necessary blocked entry, an unreachable destination and a single cell.

### Key solution

Use states `(row, column, used)`, where used is zero or one. Every move costs one, including a blocked-cell entry; unlike a free-edge coupon, the allowance does not remove the step's cost. FIFO BFS processes states by distance. A cell reached with the allowance unused is a different state from the same cell reached after using it. Mark each state discovered on enqueue.

Reference supplied on request, not a corrected user submission:

```python
from collections import deque


def shortest_route(grid: list[list[int]]) -> int:
    m, n = len(grid), len(grid[0])
    dist = [[[-1, -1] for _ in range(n)] for _ in range(m)]
    dist[0][0][0] = 0
    nodes = deque([(0, 0, 0)])
    directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

    while nodes:
        i, j, used = nodes.popleft()
        cost = dist[i][j][used]
        if i == m - 1 and j == n - 1:
            return cost
        for di, dj in directions:
            ni, nj = i + di, j + dj
            if not (0 <= ni < m and 0 <= nj < n):
                continue
            new_used = used + grid[ni][nj]
            if new_used > 1:
                continue
            if dist[ni][nj][new_used] != -1:
                continue
            dist[ni][nj][new_used] = cost + 1
            nodes.append((ni, nj, new_used))
    return -1


assert shortest_route([[0]]) == 0
assert shortest_route([[0, 0], [0, 0]]) == 2
assert shortest_route([[0, 1], [1, 0]]) == 2
assert shortest_route([[0, 1, 1, 0]]) == -1
```

There are at most two states per cell and four outgoing moves per state. BFS first dequeues a destination state at the minimum valid distance. Time and auxiliary space are both $`O(RC)`$; input is unchanged. A heap-based shortest-path algorithm can also solve the problem but does not meet the requested linear-time bound.

## Q2 — Prediction with a Shared Unknown Win Probability

### Question

A strategy has a fixed but unknown win probability P, drawn once from $`\mathrm{Uniform}(0,1)`$. Conditional on $`P=p`$, outcomes $`W_1,W_2,\ldots`$ are independent Bernoulli(p) variables. The first four outcomes are:

```math
D=(W_1,W_2,W_3,W_4)=(1,1,1,0).
```

1. Derive the conditional density of P given D, then calculate the probability that the next trade wins.
2. Calculate the probability that both of the next two trades win. Are those two outcomes independent conditional on D? Explain.
3. Let $`N=\sum_{t=5}^{14}W_t`$. Calculate $`\mathrm{Var}(N\mid D)`$. Compare it with a risk engine that treats the next ten trades as independent, each having the win probability from part 1. Explain the source of any difference.

Derive the quantities rather than quoting a conjugate-prior formula.

### Key solution

For the specified ordered record, the user's independently correct likelihood is $`p^3(1-p)`$. With uniform prior density:

```math
P(D)=\int_0^1p^3(1-p)\,dp=\frac14-\frac15=\frac1{20},
\qquad
f_{P\mid D}(p)=20p^3(1-p),\quad 0<p<1.
```

The density is zero outside that interval. The next-win probability averages p over this density:

```math
P(W_5=1\mid D)=\int_0^1p\,f_{P\mid D}(p)\,dp
=20\left(\frac15-\frac16\right)=\frac23.
```

Given the true p, two future wins have probability p squared. Averaging over the still-unknown shared parameter gives:

```math
P(W_5=W_6=1\mid D)
=\int_0^1p^2f_{P\mid D}(p)\,dp
=20\left(\frac16-\frac17\right)=\frac{10}{21}
\ne\left(\frac23\right)^2.
```

Thus future outcomes are independent given the true P, but not given only D. A higher shared P makes both outcomes more likely to be wins. Seeing a fifth-trade win updates the prediction for the sixth:

```math
P(W_6=1\mid W_5=1,D)=\frac{10/21}{2/3}=\frac57\ne\frac23.
```

For every future single trade and every distinct future pair:

```math
\mathrm{Var}(W_t\mid D)=\frac23-\left(\frac23\right)^2=\frac29,
\qquad
\mathrm{Cov}(W_i,W_j\mid D)=\frac{10}{21}-\frac49=\frac{2}{63}.
```

There are ten single variances and twice 45 unordered pair covariances:

```math
\mathrm{Var}(N\mid D)
=10\frac29+90\frac{2}{63}
=\frac{320}{63}\approx5.08.
```

The independent Bernoulli(2/3) risk engine instead gives $`10(2/3)(1/3)=20/9\approx2.22`$. It retains the correct single-trade marginal variance but omits positive pairwise dependence. The shared parameter uncertainty, rather than a causal effect of one outcome on another, creates the posterior predictive dependence.

The requested intuition follows from total variance. For a count of n future wins, conditional on current data D:

```math
\mathrm{Var}(N\mid D)
=nE[P(1-P)\mid D]+n^2\mathrm{Var}(P\mid D),
\qquad
\mathrm{Var}(N/n\mid D)
=\frac{E[P(1-P)\mid D]}n+\mathrm{Var}(P\mid D).
```

At fixed current information, averaging more future outcomes reduces independent outcome noise but does not remove uncertainty about their common P. Actually observing new data and updating the posterior can reduce that parameter uncertainty. Predictive dependence under uncertainty does not establish time dependence of outcomes conditional on the fixed true P.

**Practical discussion requested by the user:** distinguish outcome risk from uncertainty in estimated strategy quality. With a uniform prior and n conditionally independent fixed-probability observations containing k wins, posterior density is proportional to $`p^k(1-p)^{n-k}`$, and posterior mean is $`(k+1)/(n+2)`$. A posterior interval and probability of exceeding a specified benchmark convey more than the sample win rate alone. The same observed win rate with four versus hundreds of trades has different uncertainty. This simple model does not itself repair selection bias, time dependence, changing strategy quality or data leakage; win rate alone also omits payoff sizes and costs. Evaluation data not used to select the strategy and assumptions appropriate to the data remain relevant. This was a methodological explanation, not an independently submitted evaluation protocol.

## Q3 — Pooled and Within-Sector Signal Evaluation

### Question

You evaluate a stock-selection signal X against next-period return Y. Each observation belongs to sector A or B, with equal probability. Treat these as population facts:

| Quantity | Sector A | Sector B |
| --- | ---: | ---: |
| $`E[X\mid G]`$ | 2 | -2 |
| $`E[Y\mid G]`$ | 1 | -1 |
| $`\mathrm{Var}(X\mid G)`$ | 1 | 1 |
| $`\mathrm{Var}(Y\mid G)`$ | 1 | 1 |
| $`\mathrm{Cov}(X,Y\mid G)`$ | -1/2 | -1/2 |

1. Find the slope and R-squared of the population regression of Y on an intercept and X, pooling both sectors.
2. Find the coefficient on X when the regression also includes a sector indicator. Justify your calculation.
3. Explain the relationship between the two slopes. Does the pooled result establish that buying high-X stocks and selling low-X stocks within each sector has positive predictive value?

Keep the interpretation to a few interview-length sentences.

### Key solution

The pooled variables have means zero. Total variance and total covariance give:

```math
\mathrm{Var}(X)=1+4=5,\qquad
\mathrm{Var}(Y)=1+1=2,\qquad
\mathrm{Cov}(X,Y)=-\frac12+2=\frac32.
```

Thus the user's independently correct part-1 answers are:

```math
\beta_{\rm pooled}=\frac{3/2}{5}=\frac3{10},
\qquad
R^2=\frac{(3/2)^2}{5\cdot2}=\frac9{40}.
```

Let $`d=\mathbf1\{G=B\}`$ and $`z=(1,X,d)^\top`$. For $`\theta=(\alpha,\beta,\gamma)^\top`$, minimizing expected squared error yields the population normal equations:

```math
L(\theta)=E[(Y-z^\top\theta)^2],\qquad
\nabla L=-2E[z(Y-z^\top\theta)]=0,
\qquad
E[zz^\top]\theta=E[zY].
```

The residual is orthogonal to each regressor. Because $`d^2=d`$, $`E[d]=1/2`$, $`E[Xd]=-1`$ and $`E[dY]=-1/2`$, the numeric system is:

```math
\begin{pmatrix}1&0&1/2\\0&5&-1\\1/2&-1&1/2\end{pmatrix}
\begin{pmatrix}\alpha\\\beta\\\gamma\end{pmatrix}
=\begin{pmatrix}0\\3/2\\-1/2\end{pmatrix},
\qquad
(\alpha,\beta,\gamma)=(2,-1/2,-4).
```

A simpler route allows a separate sector intercept. For fixed beta, the best intercept in sector g is $`a_g=E[Y\mid G=g]-\beta E[X\mid G=g]`$. Substituting it into the residual gives a regression of sector-demeaned Y on sector-demeaned X:

```math
\widetilde X=X-E[X\mid G],\qquad
\widetilde Y=Y-E[Y\mid G],\qquad
\beta=\frac{E[\widetilde X\widetilde Y]}{E[\widetilde X^2]}
=\frac{E[\mathrm{Cov}(X,Y\mid G)]}{E[\mathrm{Var}(X\mid G)]}
=-\frac12.
```

The dummy absorbs sector mean differences, leaving the common within-sector slope. If within-sector slopes differ, a dummy alone still imposes one common slope; an X-by-sector interaction permits separate slopes.

The covariance decomposition was derived on request by taking expectations of the conditional covariance definition and subtracting $`E[X]E[Y]`$:

```math
\mathrm{Cov}(X,Y)
=E[\mathrm{Cov}(X,Y\mid G)]
+\mathrm{Cov}(E[X\mid G],E[Y\mid G]).
```

The second term treats each sector as its center point: (2,1) or (-2,-1), each with probability one half. Their mean coordinates are zero, so between-sector covariance is $`(2\cdot1)/2+((-2)(-1))/2=2`$. This positive between-sector relationship outweighs within-sector covariance -1/2. Pooled positive association therefore does not establish positive within-sector stock-selection value. Distinguish selecting sectors from selecting stocks within a sector: sector exposure can itself be useful for a mandate that allows it, but it is a different predictive claim requiring evaluation.

The requested omitted-variable calculation uses the full population regression $`Y=2-X/2-4d+\varepsilon`$, with residual orthogonal to X and d. Omitting d shifts the X coefficient by:

```math
\mathrm{Cov}(X,d)=E[Xd]-E[X]E[d]=\frac12(-2)=-1,
\qquad
\beta_{\rm pooled}-\beta
=\gamma\frac{\mathrm{Cov}(X,d)}{\mathrm{Var}(X)}
=(-4)\frac{-1}{5}=\frac45.
```

Hence $`-1/2+4/5=3/10`$. Correlation between X and an omitted regressor is only one ingredient; the omitted variable's coefficient also matters. Bias here is relative to the within-sector target: 0.3 is the correct pooled linear-projection coefficient. An error term absorbing the omitted sector effect can correlate with X, while the pooled regression's own fitted residual remains orthogonal to X. These two residual/error meanings must not be conflated; no causal conclusion follows from adding a control alone.

## Q4 — Probability Forecasts and Classification Accuracy

### Question

A model predicts whether tomorrow's return is positive: $`Y\in\{0,1\}`$. Observations belong equally often to two groups:

```math
P(Y=1\mid G=L)=0.3,\qquad P(Y=1\mid G=H)=0.9.
```

Three forecasters report:

| Forecaster | Prediction in L | Prediction in H |
| --- | ---: | ---: |
| A | 0.60 | 0.60 |
| B | 0.30 | 0.90 |
| C | 0.05 | 0.95 |

A probability forecast is calibrated when observations receiving forecast q have positive-return frequency q.

1. Which forecasters are calibrated? Justify each answer.
2. Derive and compare their population losses $`E[(Y-\widehat p)^2]`$.
3. Compare B and C's classification accuracy using cutoff 0.5. What does this comparison establish about evaluating probability forecasts using classification accuracy alone?

### Key solution

**Calibration.** A always predicts 0.6 and the unconditional positive-return frequency is $`(0.3+0.9)/2=0.6`$, so A is calibrated. B's predictions 0.3 and 0.9 separately match their conditional event frequencies. C's 0.05 and 0.95 do not. Thus A and B are calibrated; C is not. The group is known at prediction time, before observing Y; A simply ignores it. Calibration is defined conditional on the reported forecast, not automatically conditional on every available feature. A is calibrated overall without providing B's group-specific information.

**Population probability loss.** For a Bernoulli outcome with true probability p and fixed forecast q, condition on the information defining p:

```math
E[(Y-q)^2]=p(1-q)^2+(1-p)q^2
=p(1-p)+(q-p)^2.
```

The second term is squared probability error. The question asks for a population expectation over one randomly drawn observation's group and outcome; an observed sample average estimates that quantity:

```math
\widehat L=\frac1n\sum_{i=1}^n(Y_i-q_i)^2.
```

The three population losses are:

| Forecaster | Loss in L | Loss in H | Equal-weight population loss |
| --- | ---: | ---: | ---: |
| A | 0.30 | 0.18 | 0.24 |
| B | 0.21 | 0.09 | 0.15 |
| C | 0.2725 | 0.0925 | 0.1825 |

For C specifically:

```math
L_{C,L}=0.3(0.95)^2+0.7(0.05)^2=0.2725,
\qquad
L_{C,H}=0.9(0.05)^2+0.1(0.95)^2=0.0925,
\qquad
L_C=\tfrac12(0.2725+0.0925)=0.1825.
```

**Classification at cutoff 0.5.** B and C both predict zero in L and one in H. Their common accuracy is:

```math
P(\widehat Y=Y)=\tfrac12(1-0.3)+\tfrac12(0.9)=0.8.
```

Accuracy evaluates the thresholded decisions, losing probability magnitude. C is more extreme than the true probabilities and can have the same accuracy as B while having worse probability loss. A versus B shows a different distinction: both are calibrated, but B uses group information and has lower probability loss. Calibration alone does not establish useful discrimination or information content.

### Practical discussion — probability quality and decisions

The user asked how overconfidence matters when probability estimates feed position sizing, trading decisions or expected-loss calculations. In H, a forecast of 0.95 implies a negative-event probability 0.05 even though it is actually 0.10 in this model. Identical threshold decisions need not imply identical decisions under a probability-sensitive policy. Direction probability alone does not determine expected return without outcome magnitudes and costs; a better probability score does not by itself prove better trading performance.

The discussed evaluation approach has three layers:

1. **Probability scoring on the same out-of-sample observations.** Compare Brier score (the sample mean squared probability loss above) and log loss. Log loss strongly penalizes confident incorrect forecasts. These scores reflect more than calibration, so a lower score alone does not prove better calibration.

```math
\widehat L_{\log}
=-\frac1n\sum_{i=1}^n\left[y_i\log q_i+(1-y_i)\log(1-q_i)\right].
```

2. **Calibration diagnostics.** Group observations with similar predicted probabilities; compare each bin's average forecast with its observed positive-event frequency. Report bin sample counts and appropriate uncertainty intervals; also inspect relevant sectors and time periods so an aggregate check does not hide local miscalibration. For calibrated forecasts the population comparison follows the identity line; finite-sample differences require uncertainty assessment.
3. **Decision evaluation.** Fix a common probability-to-position rule, cost assumptions and risk constraints when isolating how forecast differences affect decisions. Compare out-of-sample net performance, risk, drawdowns and turnover. Fit models, any probability recalibration and decision-rule choices using earlier data, then evaluate on untouched subsequent observations; chronological validation must match deployment and information availability.

**Hit-rate curve terminology.** A curve formed by binning predicted probabilities and plotting average forecast against empirical hit rate is a reliability/calibration curve. It directly compares claimed event probabilities with frequencies; the ideal population relation is the identity line. A different curve plots a selection threshold against the hit rate among selected observations. That measures screening behavior and is not directly the same calibration diagnostic. If the horizontal axis is an arbitrary signal score rather than a probability, an identity-line calibration interpretation does not follow.

References consulted for the requested evaluation discussion: [scikit-learn probability calibration](https://scikit-learn.org/stable/modules/calibration.html), [chronological validation](https://scikit-learn.org/stable/modules/cross_validation.html#time-series-split), and [prediction probabilities versus decision thresholds](https://scikit-learn.org/stable/modules/classification_threshold.html).
