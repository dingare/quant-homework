## Q5 — LASSO versus Ridge

**Question and reference:** [L001 — Ridge Regression as PCA Shrinkage](../Questions/LinearAlgebra/L001_Ridge_Regression_as_PCA_Shrinkage.md#interview-drill--2026-10-08-q5).

### Answer and Feedback

- Result: **G/Y**. Correctly associated LASSO with dropping variables, Ridge with smoother retained weights, and preferred Ridge. Core intuition mostly correct.
- Feedback sharpened the distinction: L1 sparsity can make selection among similar predictors unstable; L2 shrinkage tends to distribute weight and stabilize weakly identified directions. Prefer LASSO when sparsity / interpretability matters; compare predictive performance using rolling out-of-sample validation.
- Regime / covariance changes can undermine historical predictive performance. That deployment example was supplied in feedback.
